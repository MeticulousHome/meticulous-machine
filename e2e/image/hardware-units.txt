# Units that fail when the image boots without the machine (e2e/image/boot.sh),
# only because what they drive is not there. One per line: a regular expression
# of the unit's name, then why. Any other unit that fails fails the check: add
# one here only with the hardware it needs, never to make a run pass.
weston\.service the display: Weston needs the machine's DRM device and tty7
meticulous-dial\.service the display: it requires Weston
variscite-wifi\.service the Wi-Fi and Bluetooth module on the SOM
variscite-bt\.service the Wi-Fi and Bluetooth module on the SOM
hostapd\.service the Wi-Fi module (access point)
usb0\.service the USB gadget port
meticulous-brightness\.service the display's backlight
meticulous-usb-current\.service the USB-C PD controller on I2C
crash-reporter@.+\.service started by the units above when they fail; it cannot upload without a network either
