# Units that fail when the image boots without the machine (e2e/image/boot.sh)
# only because what they need is not there: the machine's hardware, or a
# network (the image boots with none). One per line: a regular expression of
# the unit's name, then what it needs. Any other unit that fails fails the
# check: add one here only with what it needs, never to make a run pass.
meticulous-dial\.service the display: the Dial draws on the machine's DRM device
psplash-start\.service the display: the boot splash draws on /dev/fb0
meticulous-brightness\.service the display's backlight
meticulous-restart\.service the display: it restarts the backend and the Dial, and the Dial cannot start
variscite-wifi\.service the Wi-Fi and Bluetooth module on the SOM
variscite-bt\.service the Wi-Fi and Bluetooth module on the SOM
hostapd\.service the Wi-Fi module (access point)
usb0\.service the USB gadget port
meticulous-usb-current\.service the USB-C PD controller on I2C
rauc\.service the eMMC: its A and B slots (/dev/mmcblk2p3, p4) are not here
meticulous-smoke-report\.service a network: it publishes to hawkBit and Sentry
crash-reporter@.+\.service started by the units above when they fail; it cannot upload without a network either
